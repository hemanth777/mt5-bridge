MT5 MCP Handoff (Short, Redacted)

Base URL
- http://<MT5_HOST_IP>:8080

Auth
- Header: x-api-key: <API_KEY>

Core endpoints
- GET /health
- POST /rpc

RPC body format
{
  "function_name": "<allowed_function>",
  "kwargs": { ... }
}

Quick examples
1) Health
curl -sS http://<MT5_HOST_IP>:8080/health

2) Account info
curl -sS -X POST http://<MT5_HOST_IP>:8080/rpc \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: <API_KEY>' \
  -d '{"function_name":"account_info"}'

3) BTCUSD tick
curl -sS -X POST http://<MT5_HOST_IP>:8080/rpc \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: <API_KEY>' \
  -d '{"function_name":"symbol_info_tick","kwargs":{"symbol":"BTCUSD"}}'
